# ☕ طاسة وفنجان (Tasa & Finjan) Menu

A fast, responsive, and dynamic digital menu application for **Tasa & Finjan Cafe**. 

This menu is built using Vanilla JavaScript and dynamically fetches all its products, prices, categories, and translations directly from a connected **Google Sheet**. This allows the cafe owners to update their menu in real-time without touching a single line of code!

## 🚀 Features
- **Google Sheets Integration**: Add, edit, or remove items in real-time through a simple spreadsheet.
- **Auto-Sync**: Menu auto-refreshes seamlessly in the background to fetch the latest data.
- **Bilingual**: Full support for English and Arabic (RTL/LTR) with a seamless toggle switch.
- **Scroll Animations**: Smooth Intersection Observer animations for category reveal.
- **Responsive Design**: Mobile-first design for a native app-like experience.
- **Feedback Form**: Built-in customer feedback powered by Formspree.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript.
- **Backend / API**: Google Apps Script.
- **Database**: Google Sheets.
- **Hosting**: GitHub Pages.

## 📖 How to Update the Menu
1. Open the connected [Google Sheet](https://docs.google.com/spreadsheets/d/1AXc6R8Jy_q6zJzrUxQN-r-RjGHf4q9Q9vXmVHRW8kkc/edit).
2. Edit any row (Price, Availability, Name, Category).
3. The changes will automatically reflect on the live menu!
